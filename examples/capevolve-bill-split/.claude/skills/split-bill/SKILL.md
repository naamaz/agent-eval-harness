---
name: split-bill
description: Work out how much each person owes for a shared restaurant bill.
---

Work out what each person owes for the meal described in the arguments.

Use `scripts/split.py` (next to this file) to do the math: write the bill as
JSON in the format its docstring shows, run it, and use its numbers.

Write the result to `artifacts/split.md` as a table with one row per person
and what they owe.
